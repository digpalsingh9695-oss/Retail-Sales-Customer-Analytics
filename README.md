# Retail Sales & Customer Analytics Using SQL

## Project Overview
This project focuses on analyzing retail sales data using SQL to explore customer activity, product performance, order management, and revenue-related business questions.

The project demonstrates practical SQL skills through assignment-based questions and data analysis queries.

## Objectives
- Analyze retail orders and customer information.
- Retrieve relevant records using SQL queries.
- Combine data from multiple tables using JOINs.
- Calculate total units sold and net revenue.
- Apply aggregate functions, GROUP BY, and HAVING.
- Filter and sort results to answer business questions.

## Tools & Technologies
- **Database:** PostgreSQL
- **Language:** SQL
- **Platform:** GitHub

## SQL Concepts Covered
- SELECT and WHERE
- INNER JOIN and multi-table JOINs
- Aggregate functions such as SUM and COUNT
- GROUP BY and HAVING
- ORDER BY
- Filtering and business-condition analysis

## Business Analysis
The queries are designed to answer questions related to:
- Delivered orders and customer details
- Employee and order information
- Product category performance
- Total units sold
- Net revenue by category
- Revenue-based filtering and ranking
